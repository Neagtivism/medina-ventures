# Exodus Outreach

Templates for pitching the NFC Google Review card + analytics retainer to local businesses, and a lead-tracking format. Written for hand-off to a VA — no CRM/tooling is wired up yet, these are documentation only.

- `cold-pitch-templates.md` — in-person, email, and SMS scripts, plus objection handling.
- `lead-tracker.md` — the fields to capture per lead and how to keep the status column honest.

## For a future VA

1. Work leads from `lead-tracker.md` top to bottom by `Next Action Date`.
2. After every touch (call, email, visit), update `Status` and set the next `Next Action` + `Next Action Date` — a lead with no next action is a lead that gets forgotten.
3. Use the matching script from `cold-pitch-templates.md` for the channel, but the goal is always the same: get the free/low-cost NFC card demo in front of the owner, not to close on the first touch.
