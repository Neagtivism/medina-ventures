# Lead Tracker Template

Copy this table into a spreadsheet (Sheets/Excel) for actual day-to-day use — markdown is the field reference, not the working tool.

| Business Name | Contact Name | Phone | Email | Address | Source | Pitch Date | Status | Next Action | Next Action Date | Retainer Value ($/mo) | Card Installed (Y/N) | Notes |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | | | |

## Field definitions

- **Source** — walk-in / referral / cold email / cold call / other.
- **Status** — one of: `New` → `Contacted` → `Meeting Set` → `Demo Given` → `Closed-Won` → `Closed-Lost` → `Follow-up` (revisit later).
- **Next Action** — the single next thing to do (e.g. "send follow-up email", "call to confirm demo time"). Every lead that isn't Closed-Won or Closed-Lost must have one.
- **Next Action Date** — when that action is due. Sort the sheet by this column to know who to work today.
- **Retainer Value** — fill in once terms are agreed, even if Card Installed is still "N".
- **Notes** — objections raised, decision-maker availability, anything the next person touching this lead needs to know.

## Working rhythm

1. Sort by `Next Action Date` ascending — work top to bottom.
2. Never leave a lead with a blank `Next Action` after a touch — that's how leads go cold.
3. `Closed-Lost` leads aren't deleted — mark them and revisit in 60-90 days via the Follow-up status.
